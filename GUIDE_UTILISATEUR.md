## Premiers pas

### Création de compte

1. Cliquez sur "S'inscrire" dans la page d'accueil
2. Choisissez votre méthode d'inscription :
   - **Email et mot de passe** : classique et simple
   - **Compte Google** : connexion rapide via Firebase
3. Renseignez les informations demandées :
   - Email valide
   - Mot de passe sécurisé (8 caractères min)
   - Pseudo unique (3-20 caractères)
4. Cliquez sur "Créer mon compte"
5. Un email de vérification peut être envoyé (optionnel)

### Connexion

1. Cliquez sur "Se connecter"
2. Entrez votre email et mot de passe
3. Ou utilisez "Continuer avec Google"
4. Vous êtes redirigé vers votre dashboard

### Mot de passe oublié

1. Sur la page de connexion, cliquez "Mot de passe oublié ?"
2. Entrez votre adresse email
3. Consultez votre boîte mail
4. Cliquez sur le lien de réinitialisation
5. Définissez votre nouveau mot de passe

## Trading

Interface d'achat et vente de cryptomonnaies.

### Acheter une crypto

1. Allez dans l'onglet "Trading"
2. Section "Acheter"
3. Sélectionnez la cryptomonnaie
4. Entrez la quantité désirée
5. Le prix total s'affiche automatiquement
6. Vérifiez votre solde disponible
7. Cliquez sur "Acheter"
8. Confirmation de la transaction
9. Votre portefeuille est mis à jour

**Exemple :**
- Solde : 1000 USD
- Bitcoin : 50 000 USD
- Achat de 0.02 BTC = 1000 USD
- Nouveau solde : 0 USD
- Holdings : +0.02 BTC

### Vendre une crypto

1. Allez dans l'onglet "Trading"
2. Section "Vendre"
3. Sélectionnez la crypto que vous possédez
4. Entrez la quantité à vendre
5. Le montant en USD s'affiche
6. Cliquez sur "Vendre"
7. Confirmation de la transaction
8. Votre solde USD augmente

**Exemple :**
- Holdings : 0.02 BTC
- Prix actuel : 52 000 USD
- Vente de 0.02 BTC = 1040 USD
- Profit : +40 USD (4%)

### Conseils de trading

- **Prix en temps réel** : les cours sont mis à jour automatiquement
- **Frais** : aucun frais de transaction (simulation)
- **Liquidité** : achat/vente instantanés
- **Risques** : c'est une simulation, pas d'argent réel
- **Stratégie** : diversifiez votre portefeuille

## Indicateurs techniques

Les indicateurs aident à analyser les tendances du marché.

### RSI (Relative Strength Index)

- **Plage** : 0 à 100
- **Surachat** : > 70 (possible baisse)
- **Survente** : < 30 (possible hausse)
- **Neutre** : 30-70

**Utilisation :**
- RSI > 70 : envisager de vendre
- RSI < 30 : envisager d'acheter

### MACD

- **Signal d'achat** : ligne MACD croise au-dessus du signal
- **Signal de vente** : ligne MACD croise en dessous du signal
- **Divergences** : peuvent indiquer un retournement

### Bollinger Bands

- **3 bandes** : supérieure, moyenne, inférieure
- **Prix touche bande haute** : possiblement surévalué
- **Prix touche bande basse** : possiblement sous-évalué
- **Écart des bandes** : indique la volatilité

### Moyennes mobiles

- **SMA 7 jours** : tendance court terme
- **SMA 25 jours** : tendance moyen terme
- **SMA 99 jours** : tendance long terme

**Croix dorée** : SMA courte croise au-dessus de SMA longue (signal haussier)
**Croix de la mort** : SMA courte croise en dessous de SMA longue (signal baissier)

### Comment utiliser

1. Allez dans "Indicateurs"
2. Sélectionnez une crypto
3. Choisissez l'indicateur
4. Consultez le graphique
5. Analysez les valeurs
6. Prenez vos décisions de trading

## Alertes

Créez des alertes pour être notifié automatiquement.

### Types d'alertes

#### Alertes de prix

- **Prix au-dessus de** : notification quand le prix dépasse un seuil
- **Prix en dessous de** : notification quand le prix descend sous un seuil

**Exemple :**
- Alerte : "BTC > 60 000 USD"
- Si Bitcoin atteint 60 000 USD, vous êtes notifié

#### Alertes d'indicateurs

- **RSI surachat/survente**
- **MACD croisement**
- **Prix croise une moyenne mobile**

### Créer une alerte

1. Allez dans "Alertes"
2. Cliquez sur "Nouvelle alerte"
3. Sélectionnez la crypto
4. Choisissez le type d'alerte
5. Définissez le seuil
6. Donnez un nom à l'alerte
7. Sauvegardez

### Gestion des alertes

- **Liste des alertes** : toutes vos alertes actives
- **Statut** : active, déclenchée, désactivée
- **Modifier** : changez les paramètres
- **Supprimer** : retirez une alerte
- **Historique** : consultez les alertes passées

### Notifications

Les alertes déclenchées apparaissent :
- En temps réel sur la plateforme
- Dans votre liste de notifications
- Avec un son (si activé dans le navigateur)

## Messagerie

Communiquez avec les autres utilisateurs.

### Conversations directes

#### Démarrer une conversation

1. Cliquez sur l'icône de message
2. Cliquez sur "Nouvelle conversation"
3. Entrez le pseudo de l'utilisateur
4. Commencez à discuter

#### Lire les messages

- Cliquez sur une conversation pour l'ouvrir
- Les nouveaux messages apparaissent automatiquement
- Badge avec le nombre de messages non lus

#### Envoyer un message

1. Ouvrez une conversation
2. Tapez votre message (max 2000 caractères)
3. Appuyez sur Entrée ou cliquez sur "Envoyer"

### Messages système

Certains messages sont envoyés automatiquement :
- **[TRANSFER]** : vous avez reçu un transfert
- **[BAN]** : notification de bannissement (admins)
- **[ALERT]** : alertes administratives

Ces messages apparaissent dans une conversation spéciale.

### Notifications temps réel

- Les nouveaux messages apparaissent instantanément
- Pas besoin de rafraîchir la page
- Son de notification (optionnel)

## Transferts

Envoyez des fonds à d'autres utilisateurs.

### Effectuer un transfert

1. Allez dans "Portefeuille"
2. Cliquez sur "Transférer des fonds"
3. Entrez le pseudo du destinataire
4. Entrez le montant en USD
5. Ajoutez un motif (optionnel, max 500 caractères)
6. Cliquez sur "Envoyer"
7. Confirmez le transfert

### Validation

Le système vérifie :
- Que le destinataire existe
- Que vous avez assez de fonds
- Que vous ne transférez pas à vous-même
- Que ni vous ni le destinataire n'êtes bannis

### Notification du destinataire

Le destinataire reçoit :
- Une notification temps réel
- Un message automatique dans la messagerie
- Détails : montant, émetteur, motif

### Historique

Tous les transferts sont enregistrés :
- Transferts envoyés (en rouge)
- Transferts reçus (en vert)
- Date et heure
- Montant et motif
- Pseudo de l'autre partie

1. Dans "Profil", section "Sécurité"

3. Entrez l'ancien mot de passe
4. Entrez le nouveau (8 caractères min)
5. Confirmez le nouveau
6. Sauvegardez

### Lier un compte Discord

1. Dans "Profil", section "Connexions"
2. Cliquez sur "Lier Discord"
3. Autorisez l'accès sur Discord
4. Votre compte est lié

## Questions fréquentes

### Est-ce que je trade avec de l'argent réel ?

Non, c'est une plateforme de simulation. Tous les montants sont virtuels.

### D'où viennent les prix des cryptos ?

Les prix sont récupérés en temps réel depuis l'API CoinGecko, mise à jour toutes les 60 secondes.

### Puis-je perdre de l'argent ?

Non, car c'est une simulation. Vous pouvez perdre des fonds virtuels si vos trades sont mauvais, mais aucun impact financier réel.

### Comment ajouter plus de fonds ?

Cliquez sur "Ajouter des fonds" dans votre portefeuille. Vous pouvez ajouter autant de fonds virtuels que vous voulez.

### Les indicateurs sont-ils fiables ?

Les indicateurs techniques sont calculés selon les formules standards utilisées par les traders professionnels. Cependant, ils ne garantissent pas les performances futures.

### Combien de temps sont gardés mes données ?

Vos données sont conservées tant que votre compte existe. Historique des transactions, messages, etc. sont stockés indéfiniment (sauf suppression manuelle).

### Puis-je avoir plusieurs comptes ?

Non, un seul compte par utilisateur. Les multi-comptes peuvent entraîner un bannissement.

### Comment contacter le support ?

Envoyez un email à support@crypto-platform.com ou contactez un administrateur via la messagerie.

### Que faire si je trouve un bug ?

Signalez-le via la fonctionnalité de rapport ou contactez le support.

### La plateforme est-elle disponible sur mobile ?

Actuellement, c'est une application web responsive. Une application mobile native est prévue dans la roadmap.

### Puis-je exporter mes données ?

Oui, une fonctionnalité d'export PDF/CSV est en développement.

### Comment devenir administrateur ?

Les rôles sont attribués par les super-administrateurs. Vous ne pouvez pas vous promouvoir vous-même.

### Les conversations sont-elles privées ?

Oui, seuls les participants d'une conversation peuvent lire les messages. Les administrateurs ont accès en cas de signalement.

### Puis-je bloquer un utilisateur ?

La fonctionnalité de blocage est en développement.

### Comment fonctionne le classement ?

Un système de leaderboard basé sur les performances est prévu dans une future version.

## Conseils pour débutants

1. **Commencez petit** : testez avec de petites sommes pour comprendre
2. **Diversifiez** : ne mettez pas tous vos fonds sur une seule crypto
3. **Utilisez les indicateurs** : analysez avant d'acheter
4. **Définissez des alertes** : ne ratez pas les opportunités
5. **Consultez l'historique** : apprenez de vos erreurs
6. **Soyez patient** : le trading nécessite de la pratique
7. **Suivez les tendances** : observez les moyennes mobiles
8. **Gérez votre risque** : gardez toujours du cash disponible

## Glossaire

- **Crypto** : cryptomonnaie (Bitcoin, Ethereum, etc.)
- **Holdings** : actifs que vous possédez
- **Portfolio** : portefeuille d'investissement
- **USD** : Dollar américain
- **RSI** : Indice de force relative
- **MACD** : Convergence/divergence de moyennes mobiles
- **SMA** : Moyenne mobile simple
- **Volatilité** : amplitude des variations de prix
- **Capitalisation** : valeur totale d'une crypto sur le marché
- **Volume** : quantité échangée sur une période
